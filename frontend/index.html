Common Questions

Yes! Dhyey Clinic is designed with an offline-first architecture. All patient records, prescriptions, billing, and family data are stored locally on your clinic's computer. Internet is optional and only needed for cloud sync if configured.

A Family ID (FAM XXXX) is a unique numeric ID assigned to a household at registration. All family members are linked under this ID, eliminating duplicate records and providing a complete family health ledger. You can add, edit, or remove members at any time.

Yes. Dhyey Clinic supports role-based access for Receptionist, Doctor, Admin, and Pharmacy roles. Multiple staff can log in simultaneously with different access levels, ensuring data security and workflow efficiency.

Doctors build prescriptions directly in the system using the e-Prescription builder — entering medicine name, dosage, frequency, and instructions. Once saved, it prints a standardized, patient-friendly prescription slip with clinic letterhead and dietary recommendations.

Every visit automatically records the consultation fee and payment received. If payment is partial, the system marks an outstanding due on the patient's profile with a visual DUE badge that appears on search results. Receipts are generated and printed per visit.

Dhyey Clinic is built for speed with full keyboard control: F1 Family Reg · F2 Add Member · F3 Patient Record · F4 Dashboard · F5 Reports · F6 New Visit · F7 Billing · F8 Appointments · F9 Global Search · / Focus Search · Esc Close dialogs.
